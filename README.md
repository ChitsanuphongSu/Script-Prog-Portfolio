## Final Project

### [Gaming Statistics Dashboard](Final%20Project/Gaming-Statistics-Dashboard.md) — external reference

The inspected project is a Python/Streamlit web dashboard for exploring game data from RAWG and Steam. Its documented pages include a game library, search, details, live player counts, statistics, charts, and two-game comparison. The architecture separates API clients, processing, SQLite storage, services, UI components, analysis, and tests. Its dependencies include Streamlit, Requests, Pandas, Altair, and python-dotenv. The upstream README describes setup with project-specific requirements and a RAWG API key; see the [original repository](https://github.com/Phanuwatphk/Gaming-Statistics-Dashboard) for the current instructions.

The source is owned by `Phanuwatphk`. No redistribution license was found, so the [local reference](Final%20Project/Gaming-Statistics-Dashboard.md) contains attribution and a link; source code was not imported.

## Getting Started

The configured GitHub destination is `ChitsanuphongSu/Script-Prog-Portfolio`. To explore the collection, open a project directory and read its own README and dependency file. Once the repository is available on GitHub, clone it with:

```powershell
git clone https://github.com/ChitsanuphongSu/Script-Prog-Portfolio.git
cd Script-Prog-Portfolio
```

Example for Windows PowerShell:

```powershell
cd "Lab X Basic/Lab 11 Basic/document-automator"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Run a command only after reviewing the selected project's behavior. Dependencies vary by project; there is no repository-wide `requirements.txt`.
